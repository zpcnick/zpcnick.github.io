贪吃蛇小游戏

Posted on 2026-09-01

今天用纯 Canvas 写了一个贪吃蛇小游戏，无任何外部依赖，直接在网页上就能玩。支持键盘（方向键 / WASD）和触屏方向键，得分会自动保存到浏览器本地，刷新也不丢。下面就是可以玩的版本。

实现要点

  • 纯 Canvas 绘制：20×20 网格，每格 20px，蛇身用蓝绿渐变，蛇头带朝向眼睛。
  • 双重控制：键盘方向键 / WASD，外加屏幕方向键，方便手机操作。
  • 状态机：idle / running / paused / over 四态切换，叠加层统一处理开始、暂停、结束。
  • 防误操作：禁止 180° 反向掉头；键盘只在画布进入视口时拦截，不破坏整页滚动。
  • 动态难度：每吃一颗食物加速 4ms，下限 60ms，越往后越紧张。
  • 本地存档：最高分用 localStorage 保存，刷新页面也不丢。
  • 高分屏适配：按 devicePixelRatio 放大 backing store，Retina 屏依然清晰。
