化学元素周期表

Posted on 2026-09-28

整理了一个交互式化学元素周期表，包含全部 118 种元素，按照九大分类配色，镧系 / 锕系单独成两行放在主表下方。桌面端鼠标悬停弹出跟随卡片，显示原子序数、符号、中英文名、相对原子质量、所属周期 / 族与电子排布；移动端点击元素弹出卡片，表格支持横向滑动。

实现要点

  • 118 种元素全覆盖：主表按 18 族对齐排布，镧系（La–Lu）与锕系（Ac–Lr）单独成两行置于主表下方，列号与主表第 3–17 列严格对齐。
  • 主族 / 副族罗马编号：顶部族标号行按 IUPAC 习惯标注 —— 1、2、13–17 族为主族（IA、IIA、IIIA…VIIA），3–12 族为副族（IIIB…VIIB、VIII、IB、IIB），18 族为稀有气体 0 族。
  • 九大分类配色：碱金属、碱土金属、过渡金属、后过渡金属、类金属、非金属、稀有气体、镧系、锕系各有专属色块，顶部图例可对照，悬停图例还能高亮整类元素。后过渡金属用浅黄与过渡金属同色系但更淡，非金属蓝色不混淆。
  • 悬停跟随卡片：桌面端默认不显示详情，鼠标悬停元素时在格子附近弹出跟随卡片（自动避让边界、下方溢出时翻到上方）；点击可锁定该卡片，再次点击解锁。
  • 移动端适配：无 hover 时改为点击弹卡片，卡片浮于底部居中；表格容器横向滚动并带滚动条，18 列完整可滑。
  • 详情内容：原子序数、符号、中英文名、相对原子质量、分类、周期、族、电子排布（惰气实芯简写，如 [Ar] 3d⁶ 4s²）。
  • 零依赖：纯原生 HTML / CSS / JavaScript，无任何外部库，可直接嵌入任意静态博客。

核心逻辑

整张表是数据驱动的：118 个元素先存成一个数组，每个元素记录原子序数、符号、中英文名、质量、分类、周期、族与电子排布；渲染时按“周期 = 行、族 = 列”丢进 CSS Grid，f 区元素则按原子序数偏移到下方两行。关键代码如下：

// 元素记录：[序号, 符号, 中文, 英文, 质量, 分类, 周期, 族(0=f区), 电子排布]
var RAW = [ [1,'H','氢','Hydrogen','1.008','nonmetal',1,1,'1s¹'], /* ...118 项 */ ];

// 主表渲染：周期作行、族作列，f 区元素跳过
DATA.forEach(function(e){
  if(e.cat === 'lanthanide' || e.cat === 'actinide') return;
  var cell = makeCell(e, e.p, e.g);      // gridRow=周期, gridColumn=族
  mainGrid.appendChild(cell);
});

// f 区单独成两行：镧系按 n-56、锕系按 n-88 偏移到第 3–17 列
DATA.forEach(function(e){
  var row, col;
  if(e.cat === 'lanthanide'){ row = 1; col = (e.n - 56) + 2; }
  else if(e.cat === 'actinide'){ row = 2; col = (e.n - 88) + 2; }
  else return;
  fbGrid.appendChild(makeCell(e, row, col));
});

悬停弹出、点击锁定用的是同一个 showPop 函数：未锁定时 hover 临时显示卡片并跟随锚点定位，锁定后 hover 不再覆盖，直到再次点击解锁。整页单文件、零依赖，可以很方便地嵌进任何静态博客。
