这两个月的网站更新

Posted on2026-11-14 分类于日记

翻了一下归档才发现，从九月到现在已经连续更新了两个多月。把这段时间的改动整理成一篇日记，既是记录，也方便以后回头看。

重做首页主题

之前的首页是一条按时间排下来的文章列表，文章一多就显得杂。这次把首页改成了板块式的卡片布局，分成「教研工具」「小游戏」「日记」三个区域，顶部还加了锚点导航，可以直接跳到想看的板块。

  • 沿用蓝绿色主色，卡片加圆角和阴影，鼠标悬停时轻微上浮；
  • 每个板块显示项目数量和最近更新日期，一眼就能看出哪里刚动过；
  • 手机端自动变成单列，卡片和按钮也放大到适合手指点击的尺寸。

主题改完之后，首页不再只是「最新文章」，更像一个自己的小工作台。

四款小游戏

这两个月最花时间也最有意思的部分，是用纯 Canvas 写小游戏，全部零依赖、单文件，打开网页就能玩。

  • 贪吃蛇（09-01）：最早的一版，支持键盘和触屏方向键，得分自动保存在本地；
  • 俄罗斯方块（10-17）：加了暂存、下三个预览和幽灵投影，消行越多下落速度越快；
  • 雷电战机（10-27）：五级火力、护盾与炸弹、四种敌机和三阶段 Boss 弹幕；
  • 植物大战僵尸（11-14）：五种植物的冷却与阳光系统、三波僵尸、小推车和暂停重开。

写游戏和写普通页面最大的不同是，很多问题只有真正玩一局才会暴露：数值是不是平衡、碰撞是不是准确、手机上的按钮会不会太小。于是这两个月的周末，经常是写着写着就自己先玩上了。

四个教研工具

除了游戏，也做了一些上课能直接用的工具：

  • 化学元素周期表（09-28）：覆盖全部 118 种元素，按九大分类配色，点击即可查看原子序数、中英文名、相对原子质量与电子排布；
  • 在线分子查看器（10-17）：粘贴 XYZ 坐标就能渲染三维球棍模型，可以拖拽旋转缩放，也能单独微调某个原子；
  • 科学计算器（10-28）：参考 fx-991CN X 的布局，支持分数、三角函数与反三角、对数与指数、幂与根式、阶乘和角度制切换；
  • 原子轨道三维形状与重叠（11-01）：可旋转的 s、p、d 轨道点云，再用量子力学重叠积分的数值实验，解释不同轨道何时能有效重叠、何时被对称性严格禁戒。

它们的共同点是打开网页就能用，不用装软件，课后学生自己也能反复试。把抽象的公式和结构变成能拖动、能缩放的东西，理解起来会轻松不少。

用 Trae 做网页很方便

这段时间的页面基本都是用 Trae 配合对话完成的。我的流程很简单：先把想要的效果、交互和边界情况说清楚，让它在现有文件上改；跑起来之后自己点一遍，把不对的地方截图或者描述回去，再继续调。

  • 改主题很快：不用翻 CSS 文件找选择器，直接说「首页改成三个板块的卡片布局」，它会先读现有结构再动手；
  • 小游戏适合边玩边改：数值、碰撞、手感这类问题，玩一局就能发现，描述清楚后通常一两次就能调好；
  • 保持项目一致性：新增文章或工具时，它会照着已有页面的头部、侧栏和样式来写，不会突然换一套风格。

当然，关键的地方还是要自己确认：链接有没有指对、手机上看会不会溢出、游戏是不是真的能通关。AI 负责把想法快速变成能运行的版本，判断和取舍仍然在自己这边。

接下来

两个多月下来，网站慢慢有了自己的样子：有能上课用的工具，也有纯粹为了好玩写的小游戏。接下来想继续补一些化学和物理方向的可视化，把移动端的体验再打磨一下，也尽量保持每个月都留下一点更新记录。

写这篇日记的时候又顺手把归档和首页的数量更新了一遍——这种收尾工作，现在已经很习惯了。
