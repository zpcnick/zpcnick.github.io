无机化学常用公式速查

Posted on2026-11-24 分类于教研工具

无机化学的公式散落在各章，考前翻书常常找不到。这里用 LaTeX 排版，按「浓度与依数性 → 气体 → 热力学 → 平衡 → 酸碱 → 沉淀 → 电化学 → 动力学 → 原子结构 → 晶体与配位」的顺序整理成一张速查表，每条公式后面配一句解释，说明它在算什么、什么时候用。

浓度 依数性 气体 热力学 化学平衡 酸碱平衡 沉淀溶解 电化学 化学动力学 原子结构 晶体与配位
使用约定：浓度一律用物质的量浓度 c（mol·L−1），热力学量取标准态（p° = 100 kPa，c° = 1 mol·L−1）；带 ° 的表示标准状态，涉及 25 ℃（298 K）的近似值会单独注明。

一、浓度

物质的量浓度

\[ c_{\mathrm{B}} = \frac{n_{\mathrm{B}}}{V} \]

单位体积溶液中所含溶质 B 的物质的量，V 是溶液体积而不是溶剂体积，单位 mol·L−1。

质量分数与质量摩尔浓度

\[ w_{\mathrm{B}} = \frac{m_{\mathrm{B}}}{m_{\mathrm{tot}}}, \qquad b_{\mathrm{B}} = \frac{n_{\mathrm{B}}}{m_{\mathrm{A}}} \]

质量分数无单位，常用于市售试剂（如浓硫酸 98%）；质量摩尔浓度以 1 kg 溶剂为基准，单位 mol·kg−1，不随温度变化。

摩尔分数与稀释

\[ x_{\mathrm{B}} = \frac{n_{\mathrm{B}}}{n_{\mathrm{tot}}}, \qquad c_1 V_1 = c_2 V_2 \]

摩尔分数用于分压、活度等计算；稀释式说明稀释前后溶质的物质的量不变，注意体积单位一致。

二、稀溶液的依数性

稀溶液中，蒸气压下降、沸点升高、凝固点降低和渗透压这四类性质只取决于溶质粒子的数目，而与溶质本性无关，统称依数性。它们都以质量摩尔浓度 bB 或物质的量浓度 cB 为标度，是测摩尔质量、判断溶液性质的基础。

蒸气压下降（Raoult 定律）

\[ \Delta p = p^{\circ} x_{\mathrm{B}}, \qquad p = p^{\circ} x_{\mathrm{A}} \]

非挥发性溶质使溶剂蒸气压下降，下降值与溶质的摩尔分数成正比；xA + xB = 1，故也有 Δp/p° = xB。

沸点升高

\[ \Delta T_{\mathrm{b}} = K_{\mathrm{b}} b_{\mathrm{B}} \]

Kb 为沸点升高常数，只与溶剂有关；水的 Kb = 0.512 K·kg·mol−1，溶液沸点 Tb = Tb° + ΔTb。

凝固点降低

\[ \Delta T_{\mathrm{f}} = K_{\mathrm{f}} b_{\mathrm{B}} \]

水的 Kf = 1.86 K·kg·mol−1；溶液凝固点低于纯溶剂，冬天撒盐化雪、汽车加防冻液都利用了这一性质。

渗透压

\[ \Pi = c_{\mathrm{B}} RT \approx b_{\mathrm{B}} RT \]

半透膜两侧因浓度差产生的额外压强，单位 Pa；稀溶液中 cB ≈ bB，也可写成 ΠV = nRT。

电解质溶液与 van't Hoff 因子

\[ \Delta T_{\mathrm{b}} = iK_{\mathrm{b}} b_{\mathrm{B}}, \qquad \Delta T_{\mathrm{f}} = iK_{\mathrm{f}} b_{\mathrm{B}}, \qquad \Pi = ic_{\mathrm{B}} RT \]

i 为 van't Hoff 因子，理想情况下等于一个化学式解离出的离子数（NaCl ≈ 2，CaCl2 ≈ 3）；实际因离子缔合略小于理论值。

用依数性测摩尔质量

\[ M_{\mathrm{B}} = \frac{K_{\mathrm{f}} m_{\mathrm{B}}}{\Delta T_{\mathrm{f}} m_{\mathrm{A}}} \]

凝固点降低法最常用：mA 为溶剂质量（kg），mB 为溶质质量；也可由渗透压求 MB = mBRT/(ΠV)。

三、气体

理想气体状态方程

\[ pV = nRT \]

联系压强、体积、温度和物质的量。R = 8.314 J·mol−1·K−1，此时 p 用 Pa、V 用 m3；若 p 用 kPa、V 用 L，则 R = 8.314 kPa·L·mol−1·K−1。

分压定律（Dalton）

\[ p_i = x_i p_{\mathrm{tot}}, \qquad p_{\mathrm{tot}} = \sum p_i \]

混合气体中某组分的分压等于其摩尔分数乘以总压；排水集气时总压 = 气体分压 + 饱和水蒸气压。

分体积与密度

\[ V_i = x_i V_{\mathrm{tot}}, \qquad \rho = \frac{pM}{RT} \]

分体积是组分在总压下单独占有的体积；密度式由 pV = nRT 与 n = m/M 推出，可用于估测气体摩尔质量。

扩散定律（Graham）

\[ \frac{r_1}{r_2} = \sqrt{\frac{M_2}{M_1}} \]

同温同压下，气体扩散速率与摩尔质量的平方根成反比，轻的气体扩散得更快。

四、化学热力学

反应焓变（由生成焓计算）

\[ \Delta_{\mathrm{r}} H^{\circ} = \sum \nu_i \Delta_{\mathrm{f}} H_i^{\circ} \]

产物的标准生成焓乘系数求和，减去反应物的对应求和；稳定单质的 ΔfH° 规定为零。同理可算 ΔrG° 和 ΔrS°。

吉布斯自由能判据

\[ \Delta G = \Delta H - T\Delta S \]

恒温恒压下，ΔG < 0 反应自发，ΔG = 0 处于平衡，ΔG > 0 非自发。焓减、熵增都有利于自发，温度通过 TΔS 项起作用。

标准自由能与平衡常数

\[ \Delta_{\mathrm{r}} G^{\circ} = -RT \ln K^{\circ} \]

把热力学和平衡连起来：K° 很大说明反应在标准态下进行得彻底，ΔrG° 越负。

任意状态下的自由能

\[ \Delta_{\mathrm{r}} G = \Delta_{\mathrm{r}} G^{\circ} + RT \ln Q \]

Q 是反应商，形式与平衡常数相同但用当前浓度／分压。它把「标准态是否自发」修正为「实际状态下是否自发」。

五、化学平衡

标准平衡常数

\[ K^{\circ} = \prod \left( \frac{p_i}{p^{\circ}} \right)^{\nu_i} \]

生成物项在分子、反应物项在分母，指数为化学计量数；纯固体、纯液体和稀溶液中的溶剂不写入表达式。溶液反应把 pi/p° 换成 ci/c°。

Kp 与 Kc 的换算

\[ K_p = K_c (RT)^{\Delta n} \]

Δn 是气态生成物与气态反应物的计量数之差；Δn = 0 时两者数值相等。

反应方向判据

\[ Q \lt K \qquad Q = K \qquad Q \gt K \]

依次对应反应正向进行、达到平衡、逆向进行。比较反应商与平衡常数的相对大小即可判断移动方向，这就是勒夏特列原理的定量版本。

温度对平衡的影响（van't Hoff）

\[ \ln \frac{K_2}{K_1} = -\frac{\Delta H^{\circ}}{R} \left( \frac{1}{T_2} - \frac{1}{T_1} \right) \]

吸热反应升温 K 增大，放热反应升温 K 减小；在 ΔH° 近似不变的前提下成立。

六、酸碱平衡

pH 与水的离子积

\[ \mathrm{pH} = -\lg[\mathrm{H}^{+}], \qquad K_{\mathrm{w}} = [\mathrm{H}^{+}][\mathrm{OH}^{-}] = 1.0 \times 10^{-14} \]

pH 是氢离子浓度的负对数（严格说是活度）；298 K 时 Kw = 10−14，故 pH + pOH = 14，温度升高 Kw 增大。

共轭酸碱对

\[ K_{\mathrm{a}} \cdot K_{\mathrm{b}} = K_{\mathrm{w}} \]

酸越强其共轭碱越弱；已知 Ka 可直接求共轭碱的 Kb，反之亦然。

一元弱酸的近似 pH

\[ \mathrm{pH} \approx \frac{1}{2} \left( \mathrm{p}K_{\mathrm{a}} - \lg c \right) \]

当 c/Ka ≥ 500 且忽略水的电离时使用；本质是解 Ka = x2/(c − x) 的近似结果。

缓冲溶液（Henderson–Hasselbalch）

\[ \mathrm{pH} = \mathrm{p}K_{\mathrm{a}} + \lg \frac{c_{\mathrm{b}}}{c_{\mathrm{a}}} \]

ca、cb 分别为弱酸与其共轭碱的浓度；pH 由 Ka 和浓度比决定，稀释时比值不变、pH 基本不变。

七、沉淀溶解平衡

溶度积与溶解度

\[ \mathrm{AB}: K_{\mathrm{sp}} = s^2, \qquad \mathrm{AB_2}: K_{\mathrm{sp}} = 4s^3 \]

难溶电解质饱和溶液中各离子浓度（以计量数为指数）的乘积。s 为溶解度（mol·L−1），同类型物质才能直接比较 Ksp 大小。

溶度积规则

\[ Q \lt K_{\mathrm{sp}} \qquad Q = K_{\mathrm{sp}} \qquad Q \gt K_{\mathrm{sp}} \]

依次对应不沉淀、饱和、生成沉淀。把实际离子积 Q 与 Ksp 比较即可判断是否生成沉淀，也是分步沉淀和沉淀转化的依据。

同离子效应

\[ \mathrm{AgCl(s)} \rightleftharpoons \mathrm{Ag}^{+} + \mathrm{Cl}^{-} \]

加入共同离子（如 Cl−）后平衡左移、溶解度 s 下降。例如在 AgCl 饱和液中加 NaCl，Cl− 浓度升高使 AgCl 溶解度减小；洗涤沉淀时常用含共同离子的稀溶液。

八、电化学

电池电动势与自由能

\[ \Delta_{\mathrm{r}} G^{\circ} = -nFE^{\circ}, \qquad E^{\circ}_{\mathrm{cell}} = E^{\circ}_{+} - E^{\circ}_{-} \]

n 为转移电子数，F = 96485 C·mol−1；E°cell > 0 表示标准态下反应自发。

能斯特方程（298 K）

\[ E = E^{\circ} - \frac{0.0592}{n} \lg Q \]

浓度或分压偏离标准态时对电极电势的修正；0.0592 V 是 2.303RT/F 在 298 K 的数值。

电动势与平衡常数

\[ \lg K^{\circ} = \frac{nE^{\circ}}{0.0592} \]

由 ΔG° = −nFE° 和 ΔG° = −RT ln K° 联立得到，说明电池电动势越大，反应平衡常数越大。

九、化学动力学

反应级数速率方程积分式半衰期
零级\( v = k \)\( c = c_0 - kt \)\( t_{1/2} = c_0/(2k) \)
一级\( v = kc \)\( \ln c = \ln c_0 - kt \)\( t_{1/2} = \ln 2 / k \)
二级\( v = kc^2 \)\( 1/c - 1/c_0 = kt \)\( t_{1/2} = 1/(kc_0) \)

半衰期的含义

\[ t_{1/2} = \frac{\ln 2}{k} \approx \frac{0.693}{k} \]

一级反应的半衰期与初始浓度无关，每经过一个半衰期浓度减半，这是放射性衰变和一级水解的共同特征；零级、二级的半衰期则依赖初始浓度。

阿伦尼乌斯方程

\[ k = A e^{-E_{\mathrm{a}}/(RT)} \]

速率常数随温度升高而增大，Ea 是活化能，A 是指前因子；活化能越大，温度影响越明显。

由两个温度求活化能

\[ \ln \frac{k_2}{k_1} = \frac{E_{\mathrm{a}}}{R} \left( \frac{1}{T_1} - \frac{1}{T_2} \right) \]

已知两个温度下的速率常数即可反算活化能，是实验测定 Ea 的常用方法。

十、原子结构与周期律

氢原子能级

\[ E_n = -13.6 \, \frac{Z^2}{n^2} \ \mathrm{eV} \]

类氢离子的能级只由主量子数 n 和核电荷 Z 决定，n 越大能量越高、越靠近 0；负号表示电子被束缚。

里德伯公式

\[ \frac{1}{\lambda} = R_{\mathrm{H}} \left( \frac{1}{n_1^2} - \frac{1}{n_2^2} \right) \]

计算氢原子光谱线的波长，RH ≈ 1.097×107 m−1；n1 决定谱线系（如 n1 = 2 为巴尔末系）。

有效核电荷

\[ Z^{*} = Z - \sigma \]

内层电子对外层电子的屏蔽使核电荷「打折」，σ 为屏蔽常数；同周期从左到右 Z* 增大，原子半径减小、电离能增大。

电负性（Mulliken）

\[ \chi \approx \frac{I + A}{2} \]

电离能 I 与电子亲和能 A 的平均值，衡量原子在分子中吸引电子的能力；χ 越大非金属性越强。

十一、晶体结构与配位化学

晶胞密度

\[ \rho = \frac{ZM}{N_{\mathrm{A}} V} \]

Z 为晶胞内化学式单元数，M 为摩尔质量，V 为晶胞体积；已知密度可反推晶胞参数或 Z。

半径比规则

\[ \frac{r_+}{r_-} \]

用阳离子与阴离子的半径比预测配位数：0.225–0.414 为四面体配位（4），0.414–0.732 为八面体配位（6），0.732–1.0 为立方体配位（8）。

配位稳定常数

\[ \beta_n = \frac{[\mathrm{ML}_n]}{[\mathrm{M}][\mathrm{L}]^n}, \qquad K_{\mathrm{inst}} = \frac{1}{K_{\mathrm{f}}} \]

稳定常数 Kf（总稳定常数即 βn）越大，配合物越稳定；逐级稳定常数相乘得到 βn，不稳定常数 Kinst 是其倒数，可用于判断配位反应的方向。

磁矩与未成对电子

\[ \mu = \sqrt{n(n+2)} \ \mu_{\mathrm{B}} \]

n 为未成对电子数，μB 为玻尔磁子；实测磁矩可帮助判断配合物是内轨型还是外轨型、中心离子是否高自旋。

公式只是工具，真正要记住的是每个符号的含义、适用条件和单位。做题时先判断属于哪一类平衡（酸碱、沉淀、配位、氧化还原），再选对应的式子，能少走很多弯路。
