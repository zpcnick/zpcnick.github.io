在线分子查看器

Posted on 2026-10-17

参考 liwt31 写的在线分子查看器，根据XYZ实时出图。

用纯 Canvas 把它重新实现了一遍，并补上了两个功能：xyz 坐标轴和单原子位置微调。

完成分子建模工具可用moldraw工具。

支持标准 XYZ 格式（首行原子数 + 次行注释），或直接逐行写「元素 x y z」；空行与 # 开头的行会被忽略。微调结果会自动同步回上方文本框。

功能与实现要点

  • 纯 Canvas 手写三维：不引入 Three.js / 3Dmol.js，自己做旋转矩阵 + 透视投影 + 画家算法（按景深排序后再画），原子球用径向渐变模拟高光。整个页面零外部依赖。
  • 自动成键：内置 96 种元素的共价半径表（Cordero 2008）。距离小于 (r₁+r₂)×1.25 判定成键，再按距离比 0.82 / 0.91 区分三键与双键；双键、三键用平行线绘制。
  • xyz 坐标轴：以坐标原点为起点绘制 X（红）/ Y（绿）/ Z（蓝）三轴，箭头与轴标自动跟随旋转，取景时会把坐标轴端点一并纳入，可随时用开关隐藏。
  • 单原子位置微调：点击选中原子（橙色圆环高亮），再用 0.01 / 0.05 / 0.1 / 0.5 Å 的步长沿 x、y、z 逐轴加减，也可以直接在输入框里键入精确坐标。改动会实时重算成键，并同步写回下方文本框，支持逐次撤销。
  • 交互：拖拽旋转、滚轮（或 ＋/－ 按钮）缩放、悬停高亮、点击选中、一键重置视角。

核心逻辑

整个查看器最关键的两段代码是成键判定与透视投影：前者决定哪些原子之间连线、连线用几条平行线；后者把三维坐标搬到二维画布上，并让近处的原子看起来更大。

输入坐标 → 自动成键 → 三维渲染 → 选中微调，整条链都在浏览器里完成，没有任何后端。试试把默认的甲烷换成 C=C 乙烯、O=C=O 二氧化碳或苯环，看看多重键和坐标轴的表现。
