用 Vibe Coding 改造博客

Posted on 2026-07-31

用 Vibe Coding 改造博客：从配色到交互的全流程记录

什么是 Vibe Coding

Vibe Coding（氛围编程）是一种借助 AI 助手，通过自然语言对话来驱动开发的模式。你只需要描述想要的效果，AI 助手帮你完成代码编写、调试和部署。

今天我用这种方式对博客进行了一次全面改造，本文记录了整个过程。

第一步：更换清新蓝绿配色

原来的博客是默认的黑白灰配色，看起来比较单调。我向 AI 助手说了一句：

"更换一个更好看的风格"

AI 助手帮我修改了 css/main.css，做了以下调整：

  • 配色变量：页面背景从纯白改为浅薄荷绿 #f0f7f4，品牌色从深灰改为蓝绿 #2c7a7b
  • 卡片化设计：文章块增加 12px 圆角和柔和阴影，悬停时上浮
  • 品牌区渐变：蓝绿渐变背景 linear-gradient(135deg, #2c7a7b, #38a89d)
  • 细节美化：圆形头像、圆角代码块、蓝绿滚动条、选中文字高亮

第二步：响应式适配

问了一句"手机和电脑访问怎么样"，AI 助手用浏览器自动化工具测试了两种设备：

  • 桌面端：布局正常，无溢出，侧边栏可展开
  • 移动端：发现有横向溢出和触摸目标过小的问题

修复措施：

  • 侧边栏按钮从 24×24px 增大到 44×44px（符合触摸目标标准）
  • 图片、视频、表格设置 max-width: 100% 防止溢出
  • 添加 word-wrap: break-word 防止长 URL 撑破布局

第四步：首页只显示标题

想要首页更简洁，只显示文章标题，点击才进入详情。实现方式：

加上悬停上浮效果和蓝绿色高亮，首页变得清爽又好看。

第五步：新建 About 和 Schedule 页面

导航栏的 About 和 Schedule 链接原本打不开。AI 助手参考现有的 Archives 页面模板，创建了两个新页面：

  • About：个人介绍 + 联系方式
  • Schedule：近期计划（Q3/Q4）+ 更新记录

两个页面都沿用了蓝绿配色和卡片式布局。

总结与反思

Vibe Coding 的优势

  • 效率高：从配色设计到响应式适配，整个过程通过对话完成
  • 零门槛：不需要记住 CSS 属性名，描述效果即可
  • 自动验证：AI 助手可以用浏览器自动化工具截图检查效果
  • 迭代快：发现问题→描述问题→修复，一气呵成

Vibe Coding 的技巧

  • 描述要具体：说"更好看"不如说"蓝绿配色、圆角、卡片阴影"
  • 分步走：一次只做一个改动，验证后再进行下一步
  • 及时反馈：发现问题立刻告知，AI 能快速定位修复
  • 保留控制权：推送代码、合并分支等操作由自己确认

技术细节

本次改造的所有修改都集中在 css/main.css 中，没有改动 Hexo 主题的核心文件。主要技术点：

  • CSS 变量统一管理配色
  • @media 媒体查询实现响应式
  • transition 和 transform 实现交互动画
  • !important 覆盖主题默认样式
  • GitHub Pages 部署只需 push 到 master 分支
